# Job Sheet Privacy Policy

Last updated: August 24, 2026

Job Sheet helps users copy job-posting information into a Google spreadsheet selected by the user.

## Data the extension accesses

Job Sheet reads the active job page to identify details such as job title, requisition number, organization, application deadline, and source URL. It accesses the Google spreadsheet selected by the user so it can read worksheet headings and add application records.

## How data is used

Page information is shown to the user for review and is sent to Google Sheets only after the user submits the record. Spreadsheet identifiers and the selected worksheet are stored in Chrome synchronized storage so the extension can remember the user's destination.

## Data storage and sharing

Job Sheet does not operate an external server or database. Job records are stored in the user's Google Sheet. The extension does not sell user data, use it for advertising, or share it with third parties except Google services required to authenticate the user and update the selected spreadsheet.

## User control

Users can edit every extracted field before saving. They can disconnect their Google account from the extension settings, revoke Job Sheet access from their Google Account permissions, remove the extension, or delete records directly from their spreadsheet.
