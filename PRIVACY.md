# Job Sheet Privacy Policy

Last updated: August 24, 2026

Job Sheet helps users copy job-posting information into a Google spreadsheet selected by the user and save a PDF copy of the job description in their Google Drive.

## Data the extension accesses

Job Sheet reads the active job page to identify details such as job title, requisition number, organization, application deadline, job description, and source URL. It accesses the Google spreadsheet selected by the user so it can read worksheet headings and add application records. It creates a `Job Sheet PDFs` folder and job-description PDF files in the user's Google Drive.

## How data is used

Page information is shown to the user for review. Only after the user submits the record, Job Sheet generates a PDF from the extracted job description, uploads that PDF to the user's Google Drive, and writes the reviewed record and PDF link to Google Sheets. Spreadsheet identifiers and the selected worksheet are stored in Chrome synchronized storage so the extension can remember the user's destination.

## Data storage and sharing

Job Sheet does not operate an external server or database. Job records are stored in the user's Google Sheet, and generated PDFs are stored in the user's Google Drive. The extension does not sell user data, use it for advertising, or share it with third parties except Google services required to authenticate the user, update the selected spreadsheet, and create the requested PDF files in Drive.

## User control

Users can edit every extracted tracker field before saving. They can disconnect their Google account from the extension settings, revoke Job Sheet access from their Google Account permissions, remove the extension, delete records directly from their spreadsheet, or delete generated files and the `Job Sheet PDFs` folder from Google Drive.
